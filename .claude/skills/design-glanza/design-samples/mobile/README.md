## Kind
Platform sample, not a domain sample — selected by platform (a mobile-first
product) independently of whichever domain sample also applies, per
`design-reference-engine/reference-selection.md`'s platform-vs-domain
independence note. A mobile-first Healthcare product, for example, may draw
from both `healthcare/` (domain) and this folder (platform).

## Suggested starting register
Consumer Playful by default (`ui-engine/visual-trends.md`), overridden by
the paired domain sample's register where the two disagree (the domain's
register generally governs; this folder's contribution is platform-specific
patterns — touch-target sizing, gesture conventions, bottom-nav placement —
not a competing color/density register).
