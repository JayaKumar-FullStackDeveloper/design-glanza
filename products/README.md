# products/

Generated Product Builder skills live here, one folder per product:

```
products/
└── <product-name>/
    └── SKILL.md   (+ any supporting files)
```

Each folder is a self-contained, domain-specific skill generated by Design-Glanza from
a specific product requirement. Nothing here is hand-authored as part of Design-Glanza's
core logic — it's all output of the Intake/Empathize/Define/Ideate/Architect pipeline.
